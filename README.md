# Сантехмаркет «Дюйм» — лендінг і конструктор проєкту

Односторінковий сайт для сантехмаркету «Дюйм» (Івано-Франківськ) — магазину-конструктора,
який підбирає сантехніку, меблі та опалення під конкретний об'єкт, а не продає зі складу.

## Живі адреси

- Vercel: https://duym-santehmarket.vercel.app
- GitHub Pages: https://viktoriiamarkovska.github.io/duym-santehmarket/

Обидві оновлюються автоматично при пуші в `main`.

## Що всередині

`index.html` — увесь сайт в одному самодостатньому файлі: розмітка, стилі, скрипти
та фотографії (вшиті як base64). Немає збірки, залежностей і зовнішніх запитів, окрім
Google Fonts. Достатньо відкрити файл у браузері або залити на будь-який хостинг.

### Секції
- Верхня панель із рейтингом, адресами та телефонами
- Герой із фоновим фото та двома CTA
- «Чому магазин-конструктор?» — чотири принципи роботи
- Каталог рішень: 6 категорій із фільтром за напрямом (без кошика)
- Послуги монтажу
- Калькулятор кошторису — форма з трьох кроків
- Шоуруми: головна локація + 5 точок мережі з маршрутами
- Підвал із повним індексом адрес

### Конверсія
Замість кошика — модальна форма заявки, що відкривається з темою обраної категорії.
Обидві форми (модалка й калькулятор) віддають дані в одну функцію `submitLead(payload)` —
її треба підключити до пошти, CRM або Telegram-бота.

## Дизайн-система

Побудовано на токенах дизайн-системи «Дюйм»: тепла stone-палітра, акцент `#2C5978`,
Alegreya для заголовків і Commissioner для тексту, радіуси 6/10/16 px, м'які теплі тіні.

## Що варто замінити

- Логотип — зараз текстовий знак, бо є лише JPEG-кроп на світлому фоні. Потрібен SVG.
- Фотографії — зараз тимчасові знімки з Unsplash. Замінити на реальні фото шоурумів і товарів.
- `submitLead()` — підключити до реального обробника заявок.
